# shrinks: a form not listed here fails as new, and a line whose form is gone
# fails as stale. Converting a file means deleting its lines in the same change.
#
# Classes:
#   untyped-tool:<file>:<tool>     word, response, boundary, or stateful_internal
#                                  tool with no signature
#   uncategorized-tool:<file>:<tool> tool with no category; srd051 R6.15
#   prose-defaulted:<file>:<tool>  signed tool still carrying a block equal to
#                                  its category default, so deleting it changes
#                                  nothing
#   long-declaration-file:<file>   declaration YAML over 300 lines; split it or
#                                  extract a fragment (execution constitution E11)
#   single-importer-unit:<file>    unit with one importer and no instantiation;
#                                  fold it back (type-only units and agent-core's
#                                  library are exempt). No entries: the class
#                                  started clean.
