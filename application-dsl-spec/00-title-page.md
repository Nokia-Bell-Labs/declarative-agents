# Libretto: A Declarative Language for Applications, Agents, and Machines

Libretto is the declarative language of applications, agents, and machines:
`application.yaml`, `profile.yaml`, `machine.yaml`, tool declarations, and
REST definitions. This specification enables third-party
implementations and mechanical conformance checks by audit machinery. A
libretto is a declared text performed; here, documents are the declared text,
and running instances are the performances (chapter 02 records the rationale).

`language.yaml` defines normative statements, each with a unique identifier,
RFC 2119 requirement level, conformance target, and acceptance evidence. Prose
chapters reference these statements by identifier, ensuring verifiability at
the source. The directory retains its name: `application-dsl-spec/`.
