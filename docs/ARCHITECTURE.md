## Overview

The technical program manager writes here the system's structure: its parts, their owners, and how they connect. Under the headings below, the technical program manager adds the interfaces the system defines and implements, the parts of the system and the components each holds, and each design decision with the alternatives it rejected, each as its own node. This document is the index: a part or a decision that needs more than a paragraph, such as how the system runs or is deployed, is described in an engineering document under docs/engineering/ and named here.
